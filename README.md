# MPM Group — Organic Syntheses Laboratory

Academic research website for **Dr. Milind P. Meshram**, Assistant Professor of Chemistry at K.T.H.M. College, Nashik.

## Pages

- **Home** — lab introduction and PI overview
- **Research** — DST-SERB project and research aims
- **Publications** — searchable / filterable paper list
- **People** — PI, students, and group photographs
- **Lab** — equipment and gallery
- **About** — CV-style academic profile
- **Contact** — email, phone, address, Scholar link

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
